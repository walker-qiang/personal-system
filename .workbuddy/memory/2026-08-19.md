## 理解了 personal-system 项目
- 用户 qiang.lilq 的个人系统工作区，代号"筋斗云"，本地优先、Git 同步、AI 原生的 Personal Intelligence & Decision OS。
- 顶层 `personal-system` 是 governance 仓；四个独立 Git 子仓：`personal-assets`(Durable Source of Truth / Obsidian Vault)、`personal-os`(Go API + macOS App + Web fallback，V1 投资快照)、`personal-agent`(Python LangGraph Agent Runtime)、`personal-tools`(MCP/脚本)。
- 架构宪法：Vault owns truth / App owns experience / AI proposes meaning / User owns judgment。运行态(SQLite/cache/runtime memory)不得进 Vault。
